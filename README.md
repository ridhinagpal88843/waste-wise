# WasteWise – Waste Segregation Guide

WasteWise is a responsive, frontend-only educational website designed to help students understand proper waste segregation and adopt responsible waste disposal habits on campus.

## Features
- Search for common waste items.
- Get guidance on the correct waste category and disposal bin.
- Explore waste segregation tips.
- Take an interactive waste management quiz.
- Track quiz progress and scores.
- Restart the quiz and save the best score using browser LocalStorage.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run
1. Download or clone the project repository.
2. Open the `wastewise` folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the VS Code Live Server extension.

## Deployment
WasteWise can be deployed independently using Vercel.

- Framework Preset: Other
- Build Command: Leave blank
- Output Directory: `.`

## Project Type
Frontend-only web application. No backend or database is required. Quiz scores are stored locally in the user's browser. Waste disposal rules may vary depending on local municipal guidelines.
